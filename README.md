# Furless Customer Flutter App

Customer-facing Flutter starter connected to `/api/v1/public/bootstrap` and `/api/v1/public/enquiry`. Extend with authenticated customer portal, proposals, payment links, bookings and push notifications after Furless UAT backend is available.

## Target customer journey
Home → Services → Consultation Request → CRM Lead → Proposal → Customer Acceptance → Payment → Service / Project Status → Support.
Use the master package prototype/FURLESS_UI_Process_Flow_App_Web.html as the UX/process reference.
